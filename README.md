# resource-allocation-sql-db
MySQL relational database for handling developer skills, client projects, and project allocations.

A relational MySQL database I built to manage developer talent pools, client projects, and match skills with project requirements.

What it does?
- Tables linked using primary and foreign keys so data stays clean.
- Tracks client projects, developer skill sets, and current project assignments.
- Written SQL queries using `JOIN`s and subqueries to automatically match qualified developers with client projects.
- Tested and populated with data on my local MySQL setup.

 Tech stack
- MySQL / SQL

 How to use it
1. Open MySQL Workbench or phpMyAdmin.
2. Import the `.sql` file to create the tables and insert the sample data.
3. Run the query script to test the skill-matching logic.
